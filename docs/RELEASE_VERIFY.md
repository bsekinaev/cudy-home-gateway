# Проверка release bundle

`scripts/release/verify.py` запускается на ПК или CI с Python 3.10+.
Это проверка перед установкой: она не распаковывает и не запускает код.

Обязательные аргументы: путь к `.tar.gz`, `--commit` (полный Git SHA),
`--sha256` (ожидаемый SHA256 архива из доверенного CI-артефакта).

Проверяются SHA256 архива, project/schema/commit/version, допустимые пути,
уникальность записей, тип обычного файла, uid/gid, права, размеры и SHA256
каждого файла, отсутствие лишних файлов и обязательные entrypoints.
Ссылки, специальные файлы, абсолютные пути и переходы `..` запрещены.
Проверка версии сопоставляет manifest с HG_VERSION в common.sh.

Опция `--checksums PATH` создаёт новый LF-файл для `sha256sum -c` из корня
распакованного архива (пути начинаются с `payload/`). Существующий файл
не перезаписывается. Файл появляется только после успешной проверки.

SHA256 не подтверждает авторство: архив и ожидаемую сумму нужно получать
из доверенного запуска CI. JSON рядом с архивом не является источником
истины для этой проверки: проверяется manifest внутри архива.

Проверка не подтверждает совместимость с роутером и не выполняет
установку, резервное копирование, перезапуск служб или откат.
Эти этапы ещё предстоит реализовать и проверить отдельно.

Тесты включены в существующее обнаружение `scripts/release/test_*.py`.
