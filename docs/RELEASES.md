## Историческое обновление WAN V4

Source исторического обновления — `a277d07`. [LIVE-приёмка установки](reports/WAN_20261125_LIVE.md).
Owner-пакет V4 предназначен для baseline 1fc822c и уже применён;
повторять Apply для установленной версии не требуется. Прежние пакеты,
сеансы и receipts сохраняются для истории и восстановления.

Owner-пакет требует успешной exact-source CI/native приёмки и review, содержит
закреплённые source/baseline inventories, исходный bootstrap и непосредственный
parent. Только после этих проверок он появляется среди assets нового релиза.
VM_ONLY, универсальные исходные tar/zip GitHub и пакет миграции не подменяют
owner update.

При публикации включаются только проверенные runtime-пакеты, контрольные суммы,
общие инструкции и launcher без локального сеанса. owner-session.json, transport
logs, токены, ключи и настоящие backup/config архивы в assets не включаются.
Имеющийся резервный LAN-кабель нужен при потере обычного доступа; заранее
подключать его ради обновления не требуется.

Владелец выполняет Preflight → Apply → отдельный Verify и затем проверяет
Telegram, компьютер и REDMI. После каждого этапа сохраняются пакет, session
и подтверждения. Код отката не возвращает очередь или пользовательские данные
к старому времени.
