# Инженерные решения

## ADR-001: Telegram не является частью маршрутизации

**Решение:** бот и health engine работают как независимый control plane.

**Причина:** отказ управляющего интерфейса не должен нарушать сетевой трафик.

## ADR-002: Запрет универсального удалённого shell

**Решение:** Telegram вызывает только заранее определённые действия `gateway`.

**Не допускается:** `/exec`, `/shell`, произвольные `uci`, `nft`, `apk`, reboot и firmware update.

## ADR-003: Единый Gateway API

**Решение:** Telegram не читает конфигурацию OpenWrt напрямую. Все данные и действия проходят через CLI `gateway`, включая машинный режим `--json`.

## ADR-004: Для Telegram orchestration выбран ucode

**Решение:** системные адаптеры остаются POSIX/BusyBox shell, а Telegram orchestration и state machine реализуются на `ucode`.

**Причина:** preflight подтвердил, что `ucode` уже установлен на целевом OpenWrt и не требует добавления тяжёлого runtime. Чистый shell остаётся fallback для небольших системных adapters.

## ADR-005: Management VPN не внедряется до измерения реального RSS

**Решение:** требование «Telegram только через VPN» сохраняется, но отдельный постоянный Xray-процесс будет добавлен только после измерения `VmRSS` уже работающих Xray и Tailscale.

**Причина:** preflight показал достаточный общий запас памяти, но VSZ процессов Xray не отражает фактическое потребление RAM.

## ADR-006: Git не содержит инфраструктурные секреты

**Решение:** токены, UUID, private keys, состояния Tailscale, реальные backup-архивы и локальные секретные конфигурации исключаются из репозитория.


## ADR-007: Deployment на OpenWrt использует legacy SCP mode

**Решение:** для передачи файлов с Windows используется `scp -O`.

**Причина:** в целевом образе отсутствует SFTP server, а устанавливать дополнительный пакет только ради deployment проекта не требуется.

## ADR-008: Отсутствие публичного IPv6 не означает отсутствие IPv6 в системе

**Решение:** control plane не должен предполагать, что IPv6 sockets и служебные IPv6-адреса отсутствуют полностью.

**Причина:** preflight обнаружил IPv6 listener'ы и служебные адреса Tailscale/link-local при отключённом публичном IPv6-сценарии.
