# Home Gateway 1.0.0-rc.1

## Что входит

- Telegram показывает фактический и настроенный MAIN, сводку vtest,
  медианную скорость, задержку и результаты проверок доступности.
- recovery-review и recovery-history показывают решения мониторинга.
- recovery-scan проверяет настроенные резервы через отдельный Xray.
- В изолированных испытаниях проверены подготовка кандидата, контрольные
  суммы, одноразовый ответ LAN и откат после таймаута или перезагрузки VM.

## Что проверять перед стабильным выпуском

Рабочая смена MAIN и её откат должны пройти отдельную приёмку с настоящим
PassWall2, SOCKS 1082 и LAN-клиентом. Автоматическое управление MAIN
в этой сборке ещё не включено. Действующая версия на CUDY — 0.8.0-dev.

Проверить релиз-кандидат в OpenWrt VM, сопоставить точный SHA коммита и
архива, затем отдельно проверить работу после пробной установки.
Список обязательных проверок приведён в [плане 1.0](../superpowers/plans/2026-11-26-release-1.0.md).

## Архив и проверка

В наборе выпуска архив, SHA256 и манифест. Архив предназначен для
проверки и подачи в штатный установщик с подходящей исходной версией.
Распаковка архива вручную на рабочем CUDY не является процедурой установки.

    python scripts/release/verify.py ARCHIVE --commit COMMIT --sha256 SHA256

COMMIT указывается в манифесте, SHA256 — в отдельном файле поставки.
После санкционированной пробной установки проверяются версия, контрольные
суммы всех файлов, Telegram, WAN, DNS, MAIN и LAN. Откат и отдельный Verify
выполняются по инструкции [развёртывания](../DEPLOYMENT.md).
