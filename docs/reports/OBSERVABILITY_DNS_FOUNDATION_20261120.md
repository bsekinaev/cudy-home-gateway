## Исправление owner discovery r2

Владелец сообщил `base64: applet not found` при запуске первого пакета. Причина:
передача скрипта требовала applet, наличие которого на CUDY не было доказано.
Pipeline запустил пустой `sh`, поэтому SSH вернул успех, а проверка заголовка
корректно отказала. Это не свидетельство отказа сети или DNS.

Зависимость удалена: Windows кодирует UTF-8 байты восьмеричными escape-последовательностями,
встроенный POSIX `printf %b` передаёт их в `sh`. Размер команды ограничен до SSH.
Сначала новый regression test отклонил прежнюю base64-команду, затем прошёл.
Проверены PowerShell 5.1 и текущий PowerShell; отдельный native `ssh.exe` fixture
подтвердил точную передачу байтов через границу Windows-процесса. Захваченная
им команда выполнена BusyBox ash на стенде с запрещённым `base64`: все 9 полей
отчёта получены. **14 observability tests PASS**, реального SSH из агента не было.
Runtime DNS-адаптер в этом исправлении не менялся. Результат повторного owner
запуска ещё ожидается; REDMI endpoint не объявлен проверенным.

## Исправление owner discovery r3

Повторный запуск r2 завершился закрытием соединения сервером до заголовка.
Захваченная команда r2 содержит 12 987 символов. В
[официальном исходнике Dropbear](https://github.com/mkj/dropbear/blob/master/src/sysoptions.h)
предел exec-команды равен 9000; обработчик отклоняет превышение. Это объяснение
симптома, не чтение конфигурации production-сервера.

Новая версия отправляет короткую `sh -s -- acl_A2dNs`, а тело скрипта —
стандартным вводом UTF-8. Удалены кодирование и большой exec payload.
В изолированном тесте с **настоящими Windows OpenSSH и Dropbear** прежняя версия
получила отказ, а новая получила все 9 полей отчёта. Использованы одноразовые
ключи/known_hosts и только loopback; production CUDY не затронут.

Windows PowerShell 5.1 и текущий PowerShell: runner PASS. Native fixture:
короткая команда и stdin совпадают с исходным скриптом; лишний завершающий CRLF
PowerShell 5.1 безопасно остаётся после явного `exit 0` и проверен исполнением
настоящей оболочкой. Linux observability suite: 14 PASS, отдельный Windows
integration test явно skipped; он выполнен отдельно и PASS на Windows.
Сетевые настройки и runtime адаптер этим исправлением не меняются.
