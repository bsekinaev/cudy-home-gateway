# Происхождение иллюстраций

## Оригинальные схемы CUDY Home Gateway

`architecture`, `fresh-samples`, `coverage`, `telegram-concept` в SVG/PNG
созданы для этой документации. PNG и SVG строятся из одного описания в
`render_figures.py`; для перерисовки на Windows используется Pillow и Segoe UI.
Шрифты в файлы не встроены и отдельно не распространяются.

Это целевые схемы и вымышленные примеры. `telegram-concept` — **не скриншот**
работающего бота. Статистика 42/6/12 минут и 87,5%/80% синтетическая.
